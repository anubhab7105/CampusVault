
# Feature Implementation Workflow

Every feature must follow this lifecycle:

1. Requirement Analysis
2. Architecture Review
3. Database Design
4. API Design
5. Backend Implementation
6. Frontend Implementation
7. Real-time (if applicable)
8. Validation
9. Testing
10. Documentation
11. Security Review
12. Performance Review
13. Code Review
14. Final Acceptance

## Definition of Done
- Feature complete
- Tests passing
- Documentation updated
- Security reviewed
- Responsive UI verified
- No known regressions

Never skip any stage unless explicitly instructed.
