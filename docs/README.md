## Locked Tech Stack

Frontend:
- React
- Vite
- Tailwind CSS
- Zustand
- TanStack Query

- Socket.IO Client

Backend:
- Flask
- Flask-SocketIO
- SQLAlchemy
- Alembic

Infrastructure:
- Supabase PostgreSQL
- Supabase Storage
- Redis
- Celery
- Docker
- Gunicorn
- Nginx
- Gmail SMTP (development)
