
# Bug Fix Guide

## Workflow
1. Reproduce the bug
2. Identify root cause
3. Write or update failing test
4. Implement fix
5. Verify no regressions
6. Update documentation if needed

## Priorities
P0 - Security/Data loss
P1 - Major functionality
P2 - Minor functionality
P3 - Cosmetic/UI

## Rules
- Never patch without understanding the cause
- Prefer permanent fixes over workarounds
