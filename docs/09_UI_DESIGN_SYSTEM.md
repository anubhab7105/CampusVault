
# UI Design System

## Design Goals
- Modern SaaS
- Clean
- Responsive
- Accessible
- Consistent

## Typography
- Clear hierarchy
- Maximum readability

## Components
- Buttons
- Inputs
- Cards
- Tables
- Dialogs
- Toasts
- Skeleton loaders
- Empty states

## Tailwind Rules
- Utility-first
- Shared design tokens
- No inline styles
- Dark mode support

## Accessibility
- WCAG-aware
- Keyboard navigation
- ARIA labels where needed
