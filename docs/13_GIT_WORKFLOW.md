
# Git Workflow

## Branches
main
develop
feature/<name>
hotfix/<name>
release/<version>

## Commit Style

feat(auth): add Google OAuth
fix(chat): resolve reconnect issue
docs(api): update endpoints
refactor(files): simplify storage service
test(groups): add integration tests

## Pull Requests
- Small, focused changes
- Linked issue
- Passing CI
- At least one review
- No direct commits to main
