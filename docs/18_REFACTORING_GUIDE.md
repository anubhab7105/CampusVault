
# Refactoring Guide

## Goals
- Improve readability
- Reduce duplication
- Simplify complex logic
- Improve performance without changing behavior

## Rules
- Refactor only with tests in place
- Keep commits small
- Preserve API contracts
- Measure performance before/after major changes

## Common Targets
- Long methods
- God classes
- Duplicate business logic
- Complex conditional statements
- Large React components
